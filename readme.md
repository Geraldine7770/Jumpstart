# Just reach the key
A small 2D platformer game made with Godot, where you help a little guy
navigate through the level, avoid obstacles and find the key.

## [Play the game](https://yumiko83.itch.io/just-reach-the-key)

## About the game
**Just reach the key** is a small 2D platformer created as a game 
development project
You only need to find the key and pick it up, once you have it, you can unlock the chest
and complete the level!
Along the way, you'll need to avoid some obstacles that can make your journey more difficult

## Controls
**WASD /Arrow Keys** - Move
**Space** - Jump
